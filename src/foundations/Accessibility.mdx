## Building on it

These are the library-specific habits that keep a page conformant - the report above covers the
standard, this covers using this library.

- Reach for a **text role** (`--text-muted`, `--text-disabled`), never a raw `--gray-N`. See
  [Colour](?path=/docs/foundations-colour--docs).
- Pair any `background-color: var(--x-color)` with `var(--x-contrast)` rather than hardcoding
  white.
- Give an icon-only `Button` a `tooltip` - it supplies the accessible name as well as the visible
  hint.
- Pass `posIconLabel` whenever you pass `posIconButton`, and `aria-label` to any control whose
  label you render yourself.
