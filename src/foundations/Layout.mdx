## Spacing

<GuideNote title="The bars scale with their context" hint="not a rendering quirk">
  Spacing tokens are `em`, so the bars below are drawn at whatever the surrounding font size makes
  them. That is the point: the same token produces a tighter gap inside a small control than inside
  a large one.

## Responsive thresholds

Components measure their own container rather than the viewport, so these thresholds are mostly for
page-level layout. They are also exposed as `--breakpoint-*` custom properties for JavaScript that
needs to read one - but they cannot be used in a media query condition; use the `media-up` /
`media-down` mixins there.
