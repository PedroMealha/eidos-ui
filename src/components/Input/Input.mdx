# Input

Single-line text input supporting labels, error messages, leading/trailing icons, loading state, and four visual variants: `filled`, `outlined`, `text`, and `bare`.

> **Note**: `type="number"` gives you a numeric-only field with the same event-based `onChange` as every other `Input` type - use it when a number field should look and behave like the rest of your form. If you need increment/decrement stepper buttons, min/max clamping, or a value-based `onChange(value: number)` instead of an event, use the separate `NumberInput` component.

## Usage

```tsx
import { Input } from 'eidos-ui';
import { Mail } from 'lucide-react';

<Input label="Email" type="email" placeholder="Enter your email" preIcon={Mail} required />;
```

## States

The focus ring is painted on the `:focus-within` wrapper rather than the `<input>` itself, so it can compose with the field's elevation shadow. Unlike most controls it rings on mouse click too, which is correct for a field you are about to type into.
