# Select

Dropdown selection control that supports single and multi-select, per-option icons, disabled options, and a clearable state. Use it wherever a native `<select>` element is too limited.

## Usage

```tsx
import { Select } from '@pmealha/eidos-ui';

const options = [
  { id: '1', label: 'Apple', value: 'apple' },
  { id: '2', label: 'Banana', value: 'banana' },
  { id: '3', label: 'Cherry', value: 'cherry' },
];

<Select options={options} placeholder="Select a fruit..." />;
```

## Multiple select

Set `multiple` to allow picking more than one option. The trigger shows selected labels comma-joined; once more than 2 options are selected it switches to a compact `"N selected"` label so the field stays readable. This is a plain-text label, not removable chips - to deselect, reopen the dropdown and toggle an option off (or use the clear button to reset).
