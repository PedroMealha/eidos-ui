# PageLayout

Application shell that composes the standard page chrome - a `Toolbar`, a navigation rail, and a `Header` above the page body - into a single grid layout. Use it as the top-level layout for an authenticated app page.

> **Note**: The navigation rail is currently a fixed-width reserved region and is not yet configurable via props.

## Usage

```tsx
import { PageLayout } from '@pmealha/eidos-ui';

<PageLayout
  toolbar={{ brandName: 'Acme', avatar: { name: 'Acme' } }}
  header={{ title: 'Dashboard', subtitle: 'Overview of your account' }}
>
  <p>Page content goes here.</p>
</PageLayout>;
```
