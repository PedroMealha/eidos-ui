# PageLayout

Surface container for grouping related content. Use it to establish visual hierarchy and visually separate distinct sections within a page or layout.

> **Note**: Prefer semantic elements via `as="article"` or `as="section"` when the pagelayout represents a meaningful document section rather than a generic grouping div.

## Usage

```tsx
import { PageLayout } from '@pmealha/eidos-ui';

<PageLayout variant="outlined" padding="md">
  <h3>PageLayout title</h3>
  <p>Body content goes here.</p>
</PageLayout>
```
