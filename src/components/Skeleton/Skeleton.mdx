# Skeleton

Loading placeholder that mimics the shape of content before it arrives. Prefer it over a spinner when the layout of the incoming content is known.

## Usage

```tsx
import { Skeleton } from 'eidos-ui';

// Single text line
<Skeleton variant="text" />

// Avatar placeholder
<Skeleton variant="circular" width={40} height={40} />
```
