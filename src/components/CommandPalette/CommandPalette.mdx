# CommandPalette

A keyboard-driven command launcher presented as a floating modal - type to fuzzy-search commands and execute them instantly, à la VS Code's `⌘K` palette.

> **Note**: The palette renders via `createPortal` and manages its own focus trap. `open` / `onClose` are optional - omit them and the palette manages its own open state, including the `⌘K` (customisable via `shortcutKey`) listener that opens it.

## Usage

The simplest form needs no state at all - the palette opens itself on `⌘K` / `Ctrl+K`:

```tsx
import { CommandPalette } from '@pmealha/eidos-ui';
import type { CommandItem } from '@pmealha/eidos-ui';

const items: CommandItem[] = [
  { id: '1', label: 'Go to Dashboard', group: 'Navigation', shortcut: ['⌘', 'D'] },
  { id: '2', label: 'New Document', group: 'Actions', action: () => console.log('new doc') },
  { id: '3', label: 'Open Settings', group: 'Settings', shortcut: ['⌘', ','] },
];

function App() {
  return <CommandPalette items={items} />;
}
```

Pass `shortcutKey` to change the shortcut (e.g. `'r'` for `⌘R`), or `shortcutKey={null}` to disable the built-in listener entirely if you only want to open it from your own trigger (a button's `onClick`, for instance).

If you need full external control - syncing with a URL, another piece of app state, etc - pass `open` (+ `onClose`, and `onOpen` if you also want the shortcut to still work):

```tsx
function App() {
  const [open, setOpen] = useState(false);

  return (
    <CommandPalette
      open={open}
      onOpen={() => setOpen(true)}
      onClose={() => setOpen(false)}
      items={items}
    />
  );
}
```

## Uncontrolled

Omit `open`/`onClose` entirely and the palette manages its own state, including the `⌘K` listener - no `useState`/`useEffect` required in your app.

## With groups

Items that share a `group` string are visually clustered under a labelled section heading. Groups appear in the order their first member does in the `items` array.
