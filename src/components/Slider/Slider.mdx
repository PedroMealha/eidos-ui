# Slider

Range input for selecting a numeric value within a min/max bound. Supports labels, unit strings, min/max display, and a blocked range that prevents the thumb from entering a restricted zone.

## Usage

```tsx
import { Slider } from 'eidos-ui';

<Slider defaultValue={50} label="Volume" showValue />;
```
