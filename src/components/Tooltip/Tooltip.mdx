# Tooltip

Hover-triggered floating label for non-critical supplementary information. Accepts plain text or rich React content.

> **Note**: Tooltip is hover-triggered and for supplementary hints. Popover is click-triggered and supports interactive content (forms, buttons).

## Usage

```tsx
import { Tooltip } from 'eidos-ui';

<Tooltip message="More information" placement="top">
  <Button>Hover me</Button>
</Tooltip>;
```

## Placements

`placement` is a preference, not a guarantee - the tooltip flips to the opposite side when there isn't room, and is clamped against both viewport edges on both axes.

<Canvas of={TooltipStories.Placements} />

## Triggers

`hover` is the default. `focus` is the keyboard-equivalent and is what makes a tooltip reachable without a pointer; `click` keeps it open until dismissed.
