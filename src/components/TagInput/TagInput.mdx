# TagInput

Multi-value text input where each submitted entry is rendered as a removable Chip tag. Confirm a tag by pressing Enter or comma. Supports max tag limits and custom validation.

## Usage

```tsx
import { TagInput } from 'eidos-ui';

<TagInput
  label="Technologies"
  placeholder="Add a technology…"
  onChange={(tags) => console.log(tags)}
/>;
```

## With suggestions

Pass a `suggestions` array to show an autocomplete dropdown as the user types - useful for tag pickers backed by history or a known taxonomy (e.g. "tags used before", "known categories"). Already-added tags are filtered out of the list automatically. Free-text entry via `separators` still works alongside suggestions, so users can add anything not in the list. For async/remote sources, use `onSearch` to refetch and update `suggestions` as the user types.
