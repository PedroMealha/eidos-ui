# TagInput

Multi-value text input where each submitted entry is rendered as a removable Chip tag. Confirm a tag by pressing Enter or comma. Supports max tag limits and custom validation.

## Usage

```tsx
import { TagInput } from '@pmealha/eidos-ui';

<TagInput
  label="Technologies"
  placeholder="Add a technology…"
  onChange={(tags) => console.log(tags)}
/>
```
