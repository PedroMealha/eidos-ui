# Badge

A compact label for surfacing status, category, or count information. Comes in three variants - `filled`, `outlined`, and `text` - and supports a dot mode for minimal status indicators.

## Usage

```tsx
import { Badge } from '@pmealha/eidos-ui';

// Status label
<Badge color="success" variant="outlined">Active</Badge>

// Numeric count clamped at 99
<Badge color="danger" max={99}>{120}</Badge>

// Dot indicator
<Badge dot color="warning" />
```
