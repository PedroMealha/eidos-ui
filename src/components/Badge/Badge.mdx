# Badge

A small counter or dot pinned to a corner of another element - a notification count on a bell icon, a presence dot on an avatar. Badge always wraps `children` (the element it attaches to) and positions itself absolutely over one of its corners.

> **Note**: Looking for a standalone, fully-rounded status label like "Active" or a count that isn't attached to anything else? That's `Pill`, not `Badge`.

## Usage

```tsx
import { Badge } from 'eidos-ui';

// Notification count
<Badge content={4} color="danger">
  <IconButton icon={Bell} aria-label="Notifications" />
</Badge>

// Count clamped at 99
<Badge content={150} max={99} color="danger">
  <IconButton icon={ShoppingCart} aria-label="Cart" />
</Badge>

// Presence dot, pulled in to follow a circular child
<Badge dot color="success" overlap="circular">
  <Avatar name="Jane Doe" />
</Badge>
```

## Counts

`content` accepts a number (or any node). Set `max` to cap the displayed value at `max+`. A badge with no `content` (and `dot` unset) or `content={0}` (unless `showZero`) renders nothing, but stays mounted.

## Dot

Use `dot` for a minimal presence/status indicator with no count.

<Canvas of={BadgeStories.Dot} />

## Overlap

Position the badge relative to the corner of the wrapped element. `circular` pulls it in slightly to sit on the edge of a round child like `Avatar`; `rectangular` (default) suits square/rectangular children like icons and buttons.
