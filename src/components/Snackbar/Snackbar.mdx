# Snackbar

Toast notification system that displays temporary messages to users. Wrap your app with `SnackbarProvider` once, then trigger notifications from anywhere in the tree via the `useSnackbar` hook.

> **Note**: `SnackbarContainer` must be rendered inside `SnackbarProvider` - it is the portal mount point where toasts are injected into the DOM.

## Usage

```tsx
import { SnackbarProvider, SnackbarContainer, useSnackbar } from 'eidos-ui';

function App() {
  return (
    <SnackbarProvider>
      <YourApp />
      <SnackbarContainer />
    </SnackbarProvider>
  );
}

function YourApp() {
  const { showSuccess, showError, showWarning, showInfo } = useSnackbar();

  return <button onClick={() => showSuccess('Changes saved!')}>Save</button>;
}
```
