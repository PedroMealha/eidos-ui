# ButtonGroup

Groups adjacent `Button` components into a single visual unit. Inner border-radii are collapsed so only the two outer ends stay rounded, and the shared 1.5 px border between adjacent outlined buttons is collapsed to a single line.

Group-level `size`, `variant`, and `color` are applied as fallbacks - each child can still override them individually.

## Usage

```tsx
import { ButtonGroup, Button } from '@pmealha/eidos-ui';

<ButtonGroup variant="outlined" color="primary">
  <Button>Left</Button>
  <Button>Center</Button>
  <Button>Right</Button>
</ButtonGroup>;
```
