# Progress

Horizontal progress bar for communicating the completion percentage of a task. Use the indeterminate variant when the total work is unknown.

## Usage

```tsx
import { Progress } from 'eidos-ui';

// Determinate
<Progress value={65} />

// Indeterminate - omit value
<Progress />
```
