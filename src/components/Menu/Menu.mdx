# Menu

Dropdown action list anchored to a trigger element. Items support icons, keyboard shortcuts, dividers, nested submenus, and arbitrary React content via `component` items.

> **Note**: The exported `Menu` component is the wrapper (`MenuWrapperProps`) that accepts a `trigger` and `items` - not the internal `MenuProps` type.

## Usage

```tsx
import { Menu, Button } from 'eidos-ui';
import { User, Settings, LogOut } from 'lucide-react';

<Menu
  trigger={<Button variant="outlined">Open Menu</Button>}
  items={[
    { type: 'item', id: '1', label: 'Profile', icon: User, onClick: () => {} },
    { type: 'item', id: '2', label: 'Settings', icon: Settings, onClick: () => {} },
    { type: 'separator', id: 'sep' },
    { type: 'item', id: '3', label: 'Logout', icon: LogOut, onClick: () => {} },
  ]}
/>;
```

## With keyboard shortcuts

A `shortcut` string on an item is rendered as a [Kbd](?path=/docs/elements-kbd--docs) on the trailing edge. It is a label only - binding the actual key is the app's job.

## With a nested submenu

A `type: 'nested'` item opens a child menu. Submenus sit one z-index step above the parent (`calc(var(--z-index-dropdown) + 1)`).
