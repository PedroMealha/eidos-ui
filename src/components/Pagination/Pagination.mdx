# Pagination

Page navigation control for lists and tables. Shows first/last, previous/next, and a window of page number buttons.

> **Note**: `Pagination` is always controlled — you must manage `page` state externally and pass `onChange`.

## Usage

```tsx
import { Pagination } from '@pmealha/eidos-ui';
import { useState } from 'react';

function MyComponent() {
  const [page, setPage] = useState(1);

  return (
    <Pagination
      page={page}
      totalPages={20}
      onChange={setPage}
    />
  );
}
```
