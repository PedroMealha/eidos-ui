# Spinner

Animated loading indicator for indeterminate wait states where progress cannot be measured. For determinate progress use `Progress` instead.

## Usage

```tsx
import { Spinner } from '@pmealha/eidos-ui';

<Spinner size="md" color="primary" />
```
