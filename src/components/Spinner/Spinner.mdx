# Spinner

Animated loading indicator for indeterminate wait states where progress cannot be measured. For determinate progress use `Progress` instead.

## Usage

```tsx
import { Spinner } from 'eidos-ui';

<Spinner size="md" color="primary" />;
```

## Inside a container

The spinner centres itself against the nearest positioned ancestor, so a container only needs `position: relative`.

<Canvas of={SpinnerStories.Contained} />

> **Note**: the spinner keeps animating under `prefers-reduced-motion`. WCAG 2.3.3 targets non-essential motion, and here the motion _is_ the message - freezing it would leave an indistinguishable static arc.
