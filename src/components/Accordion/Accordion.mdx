# Accordion

Collapsible panels for showing and hiding content sections. Supports single-expand and multi-expand modes, three visual variants, and optional icons per item.

## Usage

```tsx
import { Accordion, AccordionItem } from 'eidos-ui';

<Accordion defaultValue="item1">
  <AccordionItem value="item1" label="What is eidos-ui?">
    A React component library built for speed and consistency.
  </AccordionItem>
  <AccordionItem value="item2" label="How do I install it?">
    Run npm install eidos-ui and import the components you need.
  </AccordionItem>
</Accordion>;
```
