# Avatar

Displays a user's profile picture, initials, or a fallback icon. When no `src` is provided, the component auto-derives initials and a background color from the `name` prop. Use `AvatarGroup` to stack multiple avatars with an overflow counter.

## Usage

```tsx
import { Avatar, AvatarGroup } from '@pmealha/eidos-ui';

// Image avatar
<Avatar src="https://example.com/photo.jpg" alt="Jane Smith" size="md" />

// Initials fallback — color is auto-derived from the name
<Avatar name="Jane Smith" size="md" />

// Group with overflow counter
<AvatarGroup max={4}>
  <Avatar name="Alice Johnson" />
  <Avatar name="Bob Smith" />
  <Avatar name="Carol White" />
  <Avatar name="David Brown" />
  <Avatar name="Eve Davis" />
</AvatarGroup>
```
