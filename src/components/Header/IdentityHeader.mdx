# IdentityHeader

`Header` preconfigured for the "this page is about one person or entity" shape - an avatar beside the name, supporting facts below it, actions on the end, at hero prominence. Account and profile pages both want exactly this.

> **Note**: this is deliberately one component rather than an `AccountHeader` and a `ProfileHeader`. An account leads with the organisation and a profile with the person, but the structure is identical, so two exports would render the same markup under names that suggest otherwise. A settings-style page is the genuinely different case - it has no identity to lead with, so it wants a plain `Header`.

## Usage

```tsx
import { IdentityHeader } from 'eidos-ui';
import { Pencil, Shield } from 'lucide-react';

<IdentityHeader
  title="Ana Ferreira"
  subtitle="ana.ferreira@meridian.app"
  avatar={{ name: 'Ana Ferreira', color: 'primary', size: 'xl' }}
  meta={[{ label: 'Role', value: 'Admin', icon: Shield }]}
  actions={[{ children: 'Edit profile', preIcon: Pencil, variant: 'outlined' }]}
/>;
```

## Everything else is Header

`IdentityHeaderProps` extends `HeaderProps`, so `meta`, `actions`, `collapseActionsBelow` and the rest behave exactly as documented on `Header` - including the responsive reflow, which is keyed off the header's own width rather than the viewport. See [Header](?path=/docs/layout-components-header--docs) for those.

## At default prominence

`variant="default"` keeps the avatar and metadata layout but drops back to the standard title size - for an identity header that shouldn't dominate the page it sits on.

## Custom media

`avatar` is a shorthand that renders an `Avatar` at `lg` (48px) by default. Set `avatar.size` to `xl` (64px) or `2xl` (96px) for the larger mark a profile page usually wants. Pass `media` instead for anything that isn't an avatar - a logo or an icon block. If both are given, `media` wins and a development warning is logged.
