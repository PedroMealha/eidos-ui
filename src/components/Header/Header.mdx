# Header

Page-level header combining a title, an optional subtitle and breadcrumb trail, with a set of right-aligned action buttons. Typically rendered inside `PageLayout`'s content area, above the page body.

> **Note**: `actions` accepts a restricted subset of `Button` props (`icon` for an icon-only action, or `children`/`preIcon`/`posIcon` for a labeled one) rather than the full `ButtonProps` API - see `HeaderActionProps`.

## Usage

```tsx
import { Header } from '@pmealha/eidos-ui';

<Header
  title="Dashboard"
  subtitle="Overview of your account"
  breadcrumbs={{ items: [{ label: 'Home', href: '/' }, { label: 'Dashboard' }] }}
  actions={[{ children: 'New', onClick: () => {} }]}
/>;
```
