# Breadcrumb

A navigation trail showing the current page's location within the site hierarchy. The last item is always rendered as the current (non-linked) page.

> **Note**: For SPA navigation, use the `onClick` handler on each item instead of `href` to avoid full page reloads.

## Usage

```tsx
import { Breadcrumb } from '@pmealha/eidos-ui';

<Breadcrumb
  items={[
    { label: 'Home', href: '/' },
    { label: 'Products', href: '/products' },
    { label: 'Smartphones' },
  ]}
/>
```
