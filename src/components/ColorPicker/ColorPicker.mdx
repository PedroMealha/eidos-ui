# ColorPicker

Full-featured color selector with a gradient canvas, hue and alpha sliders, hex/rgb/hsl text input, and optional preset swatches. Renders as a popover trigger by default; set `inline` for an always-visible panel.

## Usage

```tsx
import { ColorPicker } from 'eidos-ui';

const [color, setColor] = useState('#6366f1');

<ColorPicker value={color} onChange={setColor} label="Brand color" />;
```

The default mode renders a color swatch that opens a popover picker on click.

## With alpha slider

Enable `showAlpha` to reveal an opacity slider below the hue rail. The hex value gains an alpha channel (e.g. `#6366f1cc`).

<Canvas of={ColorPickerStories.WithAlpha} />

## HSL format

Set `format="hsl"` to display HSL values in the text input. The user can also switch formats manually inside the picker.
