# Radio

Single-select control that should always be used inside a `RadioGroup`, which enforces mutual exclusivity across all options sharing the same `name`.

> **Note**: For most use-cases, prefer `RadioGroup` over composing individual `Radio` elements manually - it handles `name`, state, and validation in one place.

## Usage

```tsx
import { RadioGroup } from 'eidos-ui';

<RadioGroup
  name="plan"
  defaultValue="pro"
  options={[
    { value: 'free', label: 'Free' },
    { value: 'pro', label: 'Pro' },
    { value: 'enterprise', label: 'Enterprise' },
  ]}
/>;
```
