# VirtualList

Virtualized scrolling list for rendering large datasets efficiently. Only the visible rows are in the DOM at any time.

> **Note**: Powered by `@tanstack/react-virtual` - DOM node count stays constant regardless of dataset size, making it safe to render tens of thousands of rows.

## Usage

```tsx
import { VirtualList } from '@pmealha/eidos-ui';

<VirtualList
  data={items}
  rowHeight={48}
  height={400}
  getRowKey={(item) => item.id}
  renderRow={(item) => <div>{item.name}</div>}
/>
```

All rows share the same pixel height — the simplest and most performant configuration.
