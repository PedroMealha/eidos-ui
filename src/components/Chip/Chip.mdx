# Chip

Compact inline tag for displaying categories, labels, or active filters. Accepts leading and trailing icons, a removable close button via `onRemove`, and a click handler for interactive filter patterns. Three visual styles: `filled`, `outlined`, and `text`.

## Usage

```tsx
import { Chip } from 'eidos-ui';
import { Tag } from 'lucide-react';

<Chip variant="outlined" color="primary" preIcon={Tag} onRemove={() => handleRemove('design')}>
  Design
</Chip>;
```

## Inline in text

`Chip` is `display: inline-flex`, so it sits on a text baseline without stretching to fill its container. (It explicitly overrides the `display: flex` its layout mixin would otherwise give it - a block-level flex element becomes a full-width bar the moment it is used anywhere other than inside another flex row.)

> **Note**: `Chip` renders a `<div>`, so it cannot be placed inside a `<p>` - a `div` descendant of `p` is invalid HTML and React reports it as a hydration error. Use a `div` or `span` container for text that includes chips.

## Interactive

`onClick` makes the whole chip activatable; `onRemove` adds a separate close button. They compose - a chip can be both, and the remove button stops the click from propagating to the chip itself.
