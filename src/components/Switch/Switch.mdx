# Switch

Toggle control for binary on/off settings. Prefer Switch over Checkbox when the action takes immediate effect without a submit step.

## Usage

```tsx
import { Switch } from '@pmealha/eidos-ui';

<Switch
  label="Notifications"
  defaultChecked
  onChange={(e) => console.log(e.target.checked)}
/>
```
