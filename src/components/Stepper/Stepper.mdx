# Stepper

Visual progress indicator for multi-step processes. Shows completed, active, and upcoming steps in horizontal or vertical orientation.

## Usage

```tsx
import { Stepper } from 'eidos-ui';

const steps = [
  { label: 'Account', description: 'Enter your account details' },
  { label: 'Profile', description: 'Set up your profile' },
  { label: 'Review', description: 'Review your information' },
  { label: 'Confirm', description: 'Confirm and submit' },
];

<Stepper steps={steps} activeStep={1} />;
```
