# Modal

Focused dialog that blocks the background with an overlay. Use for confirmations, forms, and detail views that require the user's full attention before continuing.

> **Note**: `title` accepts any inline node, not just a string - a status indicator beside the heading text is centered on its line, alongside the optional `icon`, and wraps below it when there isn't room for both.

## Usage

```tsx
import { Modal } from 'eidos-ui';
import { useState } from 'react';

function MyComponent() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <button onClick={() => setIsOpen(true)}>Open</button>
      <Modal isOpen={isOpen} onClose={() => setIsOpen(false)} title="Confirm Action">
        <p>Are you sure you want to proceed?</p>
      </Modal>
    </>
  );
}
```

## With a string icon

`icon` takes a component, or the name of an icon registered with `registerIcons` - so an icon can come from configuration once the app has registered the set it uses. An unregistered name is treated as icon-font classes.
