# Tabs

Content switcher with a horizontal row of labelled tab triggers. Supports underline (default), enclosed, and pills visual styles.

## Usage

```tsx
import { Tabs, Tab, TabPanel } from 'eidos-ui';

<Tabs defaultValue="overview">
  <Tab value="overview">Overview</Tab>
  <Tab value="analytics">Analytics</Tab>
  <TabPanel value="overview">Overview content</TabPanel>
  <TabPanel value="analytics">Analytics content</TabPanel>
</Tabs>;
```

## Scroll buttons

A strip wider than its container scrolls horizontally rather than overflowing the
page. With the default `scrollButtons="auto"`, previous/next buttons appear while
it overflows and the scrollbar is hidden; `scrollButtons="none"` keeps the native
scrollbar instead. Touch swipe, trackpad and shift+wheel work either way, and
activating a tab outside the visible part scrolls it into view.
