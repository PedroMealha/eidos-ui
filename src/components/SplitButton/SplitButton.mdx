# SplitButton

A two-part button with a primary action on the left and a chevron on the right that opens a dropdown of secondary actions. The two halves share a single continuous visual boundary.

Use it for "Save / Save as draft / Save as template", "Send / Schedule / Send test", or any action that has one obvious primary path and a small set of less-common alternatives.

> **SplitButton vs ButtonGroup**: ButtonGroup is for equally-weighted related actions. SplitButton is for one dominant action with secondary variants.

## Usage

```tsx
import { SplitButton } from '@pmealha/eidos-ui';

<SplitButton
  label="Save"
  preIcon={Save}
  onClick={() => save()}
  options={[
    { id: 'draft',    label: 'Save as draft',    icon: FileText, onClick: saveDraft },
    { id: 'template', label: 'Save as template', icon: Save,     onClick: saveTemplate },
    { id: 'schedule', label: 'Schedule publish', icon: Clock,    onClick: schedule },
  ]}
/>
```

## Default

Click the left part to trigger the primary action immediately. Click the chevron to reveal secondary options.
