# Pill

A compact, fully-rounded label for surfacing status, category, or count information. Comes in three variants - `filled`, `outlined`, and `text` - and supports a `dot` indicator either on its own or alongside a label.

> **Note**: Looking for a small counter/dot pinned to the corner of another element (a notification count on a bell icon, an online indicator on an avatar)? That's `Badge`, not `Pill` - see the Badge docs.

## Usage

```tsx
import { Pill } from 'eidos-ui';

// Status label
<Pill color="success" variant="outlined">Active</Pill>

// Numeric count clamped at 99
<Pill color="danger" max={99}>{120}</Pill>

// Dot-only indicator
<Pill dot color="warning" />

// Dot + label, e.g. a status pill
<Pill dot variant="text" color="success">Active</Pill>
```
