# Toolbar

Surface container for grouping related content. Use it to establish visual hierarchy and visually separate distinct sections within a page or layout.

> **Note**: Prefer semantic elements via `as="article"` or `as="section"` when the navigation represents a meaningful document section rather than a generic grouping div.

## Usage

```tsx
import { Toolbar } from '@pmealha/eidos-ui';

<Toolbar variant="outlined" padding="md">
  <h3>Toolbar title</h3>
  <p>Body content goes here.</p>
</Toolbar>
```
