# Toolbar

Top application bar pairing a breadcrumb trail with an optional command palette trigger, a set of right-aligned action buttons, and a user menu. Used as the top-level bar in `PageLayout`, but usable on its own as a page or section toolbar.

> **Note**: `actions` accepts a restricted subset of `Button` props (`icon` for an icon-only action, or `children`/`preIcon`/`posIcon` for a labeled one) rather than the full `ButtonProps` API - see `ToolbarActionProps`. `cmdPaletteItems` is optional; when supplied, `Toolbar` renders a `CommandPalette` with its built-in `trigger` (see the `CommandPalette` docs).

## Usage

```tsx
import { Toolbar } from 'eidos-ui';

<Toolbar
  breadcrumbs={{ items: [{ label: 'Home', href: '/' }, { label: 'Dashboard' }] }}
  cmdPaletteItems={[{ id: '1', label: 'Go to Dashboard' }]}
  actions={[{ icon: 'Bell', color: 'secondary', onClick: () => {} }]}
  userMenu={[{ type: 'item', id: 'logout', label: 'Logout', onClick: () => {} }]}
/>;
```
