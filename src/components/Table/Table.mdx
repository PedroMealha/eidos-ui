# Table

Read-only data table with sorting, pagination, column filters, custom cell rendering, and a per-row actions menu. For inline cell editing use `DataGrid` instead.

> **Note**: Table is for displaying data; DataGrid is for editing it. Read-only display: Table. Inline cell editing: DataGrid.

## Usage

```tsx
import { Table } from '@pmealha/eidos-ui';
import type { TableColumn } from '@pmealha/eidos-ui';

interface User {
  id: number;
  name: string;
  email: string;
}

const columns: TableColumn<User>[] = [
  { key: 'name',  label: 'Name' },
  { key: 'email', label: 'Email' },
];

<Table data={users} columns={columns} />
```

## With pagination

Enable `showPagination` and configure `pageSize` and `pageSizeOptions` to add a pagination bar below the table.

> **Note**: Table's pagination is always client-side - it slices `data` internally and has no `onPageChange`/controlled-page equivalent. If you need server-side pagination (fetching one page at a time, `totalRows` driven by the backend), use `DataGrid` instead: it supports the same client-side mode plus a server-side mode via `onPageChange` and `totalRows`.
