# FileUpload

Drag-and-drop file upload zone with a click-to-browse fallback. Supports file type restrictions, size limits, and multiple file selection.

## Usage

```tsx
import { FileUpload } from '@pmealha/eidos-ui';

<FileUpload
  onFilesAccepted={(files) => console.log(files)}
  onFilesRejected={(files, reason) => console.warn(reason, files)}
/>;
```
