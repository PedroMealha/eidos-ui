# Dropdown

A low-level floating panel anchored to any trigger element. It handles positioning, focus, keyboard dismissal, and z-index layering - making it the foundation for Menu, Select, Combobox, and other compound components. Use it directly when you need a custom floating panel not covered by those higher-level components.

> **Note**: For mutual exclusion between multiple dropdowns (only one open at a time), wrap them with `DropdownProvider` and pass a shared `dropdownGroup` string to each.

## Usage

```tsx
import { Dropdown } from 'eidos-ui';
import { Button } from 'eidos-ui';

<Dropdown
  placement="bottom"
  trigger={<Button variant="outlined">Open</Button>}
  content={
    <div style={{ padding: '1rem', minWidth: '200px' }}>
      <p>Any content goes here.</p>
    </div>
  }
/>;
```

For a real menu prefer the [Menu](?path=/docs/overlays-menu--docs) component, which builds this on top of `Dropdown` with keyboard navigation and roles already handled. Use `Dropdown` directly when the panel is not a menu.

## Placements

`placement` is a preference. The panel flips to the opposite side when the anchor has no room there, and is then clamped against both viewport edges on both axes - the flip reacts to the anchor, the clamp to the panel's own size, and both are needed.

## Custom trigger

The trigger keeps its own semantics - `Dropdown` wraps it in a plain positioning `div` carrying no `role` and no `tabIndex`. A custom trigger must therefore be a real interactive element itself, or it will be unreachable by keyboard and invisible to assistive technology.
