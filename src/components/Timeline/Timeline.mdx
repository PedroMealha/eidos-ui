# Timeline

Vertical list of time-ordered events connected by a line. Each entry has a timestamp, title, optional description, and optional icon with color.

## Usage

```tsx
import { Timeline } from 'eidos-ui';

<Timeline
  items={[
    { id: '1', title: 'Order placed', timestamp: 'Today 09:41', color: 'primary' },
    { id: '2', title: 'Payment confirmed', timestamp: 'Today 09:42', color: 'success' },
  ]}
/>;
```

## Colors

`color` takes the library's six colour names - `primary`, `secondary`, `success`, `danger`, `warning`, `info` - plus `default`, a neutral gray dot for entries that carry no status.

## Naming the list

The timeline renders an ordered list with no accessible name of its own. When a visible heading introduces it, point `aria-labelledby` at that heading. Otherwise pass `ariaLabel` - "Order history", "Experience" - when the context does not already make the list's purpose clear.

## Rich content

`title` and `description` render in `div`s, so block content is valid in both - a bullet list of achievements, a row of chips, several paragraphs. Lists inside a description get an indent so their markers stay inside the content column.
