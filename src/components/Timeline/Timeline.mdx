# Timeline

Vertical list of time-ordered events connected by a line. Each entry has a timestamp, title, optional description, and optional icon with color.

## Usage

```tsx
import { Timeline } from '@pmealha/eidos-ui';

<Timeline
  items={[
    { id: '1', title: 'Order placed', timestamp: 'Today 09:41', color: 'primary' },
    { id: '2', title: 'Payment confirmed', timestamp: 'Today 09:42', color: 'success' },
  ]}
/>
```
