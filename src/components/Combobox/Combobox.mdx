# Combobox

Searchable dropdown that combines a text input with a filtered option list. Prefer it over a plain `<Select>` for long lists, async data sources, or when free-text entry alongside suggestions is needed.

> **Note**: Every option requires a unique `id` field. For server-side filtering, pass `onSearch` together with `loading` - built-in client filtering is bypassed automatically.

## Usage

```tsx
import { Combobox } from 'eidos-ui';
import type { ComboboxOption } from 'eidos-ui';

const options: ComboboxOption[] = [
  { id: '1', value: 'react', label: 'React' },
  { id: '2', value: 'vue', label: 'Vue' },
  { id: '3', value: 'svelte', label: 'Svelte' },
];

<Combobox
  options={options}
  label="Framework"
  placeholder="Search or select…"
  onChange={(value) => console.log(value)}
/>;
```
