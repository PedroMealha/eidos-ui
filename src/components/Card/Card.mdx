# Card

Surface container for grouping related content. Use it to establish visual hierarchy and visually separate distinct sections within a page or layout.

> **Note**: Prefer semantic elements via `as="article"` or `as="section"` when the card represents a meaningful document section rather than a generic grouping div.

## Usage

```tsx
import { Card } from '@pmealha/eidos-ui';

<Card variant="outlined" padding="md">
  <h3>Card title</h3>
  <p>Body content goes here.</p>
</Card>;
```
