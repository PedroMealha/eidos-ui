# Button

Buttons trigger actions or events. Use them for the main call-to-action in a form, dialog, or card. The component supports text buttons, icon-only buttons, and a wide range of visual styles.

## Usage

```tsx
import { Button } from '@pmealha/eidos-ui';

<Button variant="filled" color="primary" size="medium">
  Click me
</Button>
```
