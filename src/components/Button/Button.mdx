# Button

Buttons trigger actions or events. Use them for the main call-to-action in a form, dialog, or card. The component supports text buttons, icon-only buttons, and a wide range of visual styles.

## Usage

```tsx
import { Button } from 'eidos-ui';

<Button variant="filled" color="primary" size="md">
  Click me
</Button>;
```

## As link

Pass `href` to render the button as a link. It looks exactly like a button, but navigates like a link - middle-click, "open in new tab" and the browser's link preview all work. Use it whenever the action _goes somewhere_, and keep `onClick` for actions that _do something_.

Links render as `<a>` by default. Wrap your app in a [`LinkProvider`](?path=/docs/navigation-linkprovider--docs) to render them with your router's link instead. A disabled or loading link has no `href`, so it cannot be followed by mouse, keyboard or assistive technology.

## Icon button

For actions represented by a single icon. Pass `icon` instead of `children` - the two are mutually exclusive in the type, so a button is either a text button or an icon button, never both.

## Icon names

Icon props also accept a string. Register the icons your app uses once, at its root, and any icon prop in the library resolves their names - kebab-case or PascalCase:

```tsx
import { registerIcons } from 'eidos-ui';
import { Rocket, Sparkles } from 'lucide-react';

registerIcons({ Rocket, Sparkles });

<Button preIcon="rocket">Launch</Button>;
```

`import 'eidos-ui/lucide-icons'` registers every Lucide icon instead - convenient, but it puts the whole icon set in your bundle. A string that isn't registered is treated as CSS classes for an icon font (`"fas fa-heart"`); a single word that isn't registered also logs a development warning, since it is usually a Lucide name someone forgot to register.

## States

`loading` swaps the label for a spinner; pass `loadingText` to keep a label alongside it. The spinner keeps animating under `prefers-reduced-motion`, since it communicates state rather than decoration.

## Variants

`filled` is the solid call-to-action, `outlined` the secondary choice, and `text` the lowest-prominence option. `text` paints no resting background - a tint appears on hover only.

## With icons

`preIcon` and `posIcon` take an icon component (`Download`) - any component that accepts `className`, from Lucide or elsewhere. Only the icons you import reach your bundle. They also accept a registered name; see [Icon names](#icon-names).
