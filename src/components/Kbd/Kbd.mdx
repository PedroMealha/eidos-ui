# Kbd

Renders a keyboard key or shortcut with a physical key appearance. Built on the native `<kbd>` HTML element for semantic correctness.

Use it in tooltips, menu item shortcuts, inline documentation, or command palettes - anywhere a keyboard shortcut needs to be communicated visually.

## Usage

```tsx
import { Kbd } from '@pmealha/eidos-ui';

// Single key
<Kbd>Enter</Kbd>

// Compound shortcut - place keys side-by-side with a separator
<span>
  <Kbd>⌘</Kbd> + <Kbd>K</Kbd>
</span>
```
