# Checkbox

Boolean toggle control for forms. Supports controlled and uncontrolled usage, an indeterminate state for parent-of-children selection patterns, four color themes, and inline error messaging.

## Usage

```tsx
import { Checkbox } from 'eidos-ui';

// Uncontrolled
<Checkbox label="Accept terms and conditions" defaultChecked />

// Controlled
<Checkbox
  label="Subscribe to newsletter"
  checked={subscribed}
  onChange={(e) => setSubscribed(e.target.checked)}
/>
```

## Disabled

A disabled checkbox is exempt from WCAG's contrast minimum - it is meant to read as unavailable - which is why it uses `--text-disabled` rather than `--text-muted`.
