# EmptyState

Placeholder shown when a list, table, or content area has no items to display. Accepts an optional icon, a required title, supporting description text, and an optional action button.

> **Note**: `title` accepts any inline node, not just a string - a status indicator beside the heading text stays centered with it and wraps below it when there isn't room for both.

## Usage

```tsx
import { EmptyState, Button } from 'eidos-ui';
import { Inbox } from 'lucide-react';

<EmptyState
  icon={<Inbox />}
  title="Your inbox is empty"
  description="New messages will appear here."
  action={<Button color="primary">Compose message</Button>}
/>;
```
