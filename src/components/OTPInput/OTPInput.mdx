# OTPInput

One-time password / verification code input rendered as individual character boxes. Handles paste, auto-focus advancement, and masked display for sensitive codes.

## Usage

```tsx
import { OTPInput } from '@pmealha/eidos-ui';

<OTPInput
  length={6}
  label="Verification code"
  hint="Enter the 6-digit code sent to your phone."
  onComplete={(code) => console.log('Code:', code)}
/>
```
