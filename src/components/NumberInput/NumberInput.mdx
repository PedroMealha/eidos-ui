# NumberInput

Numeric text input with increment/decrement controls, min/max clamping, precision formatting, and optional keyboard-only typing restriction.

> **Note**: `NumberInput` has a value-based `onChange(value: number)`, unlike every other input in this library. If you just want a plain numeric field with the same event-based `onChange` as the rest of your form (no stepper buttons, no clamping), use `Input` with `type="number"` instead.

## Usage

```tsx
import { NumberInput } from 'eidos-ui';
import { useState } from 'react';

function MyComponent() {
  const [value, setValue] = useState(0);

  return <NumberInput value={value} onChange={setValue} min={0} max={100} label="Quantity" />;
}
```

## No typing

Setting `allowTyping={false}` restricts entry to the increment/decrement buttons only - useful for bounded integer inputs like ratings or quantities where free-text entry would bypass `min`/`max`.

<Canvas of={NumberInputStories.NoTyping} />

## Precision

Use `step` and `precision` together for decimal values: `step` controls the increment amount, `precision` controls how many decimal places are displayed.

<Canvas of={NumberInputStories.Precision} />

## Read-only

The control displays its value and remains focusable, but neither typing nor the stepper buttons can change it.
