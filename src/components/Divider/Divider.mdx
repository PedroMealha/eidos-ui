# Divider

A thin visual separator line. Use it to divide sections of content horizontally, or to separate inline items in a flex layout vertically.

## Usage

```tsx
import { Divider } from '@pmealha/eidos-ui';

// Horizontal (default) - separates stacked content
<div>
  <p>Above</p>
  <Divider />
  <p>Below</p>
</div>

// Vertical - separates side-by-side items
<div style={{ display: 'flex', alignItems: 'center', height: '40px', gap: '1rem' }}>
  <span>Left</span>
  <Divider direction="vertical" />
  <span>Right</span>
</div>
```

## Default

The default orientation - a full-width horizontal rule between stacked elements. Use the controls to switch direction.

## Vertical

Set `direction="vertical"` when the divider's parent is a flex row. The divider stretches to the container's full height automatically.
