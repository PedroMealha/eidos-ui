# Alert

Inline feedback messages for communicating status, warnings, errors, and success states. Use alerts for non-blocking system messages that don't interrupt the user's workflow.

## Usage

```tsx
import { Alert } from 'eidos-ui';

<Alert variant="warning" title="Storage limit reached">
  You have used 95% of your available storage. Upgrade your plan to continue uploading.
</Alert>;
```
